# HomeHub

**HomeHub** is a centralized, property-based digital platform that serves as a living record of everything related to a home — projects, maintenance, contractors, warranties, insurance, and historical data — designed to organize and preserve a home's entire lifecycle in one place.

## Key Features

- **My Home** — Track home systems, services, and professional contacts by room or system
- **Projects** — Manage current, past, and future renovation projects
- **Home Strength** — Score-based recommendations with actionable improvement steps
- **Contractor Phonebook** — Rate, message, and manage service providers
- **PriceMatch Marketplace** — Get competitive quotes from vetted contractors
- **Maintenance Calendar** — Smart reminders with weather-triggered alerts
- **Documents** — Upload and organize warranties, permits, contracts, and invoices
- **Resale Dossier** — Transferable home history for future buyers
- **Community Hub** — Neighborhood deals, shared maintenance, and local resources
- **Global Search** — Instant search across all screens and content in every portal
- **Energy Profile** — Efficiency scoring and utility tracking
- **Insurance Module** — Policy management and claims tracking
- **QR Contractor Access** — Grant contractors time-limited property access via QR code

## How to Use

All files are self-contained single-page HTML apps — no build step or server required. Simply open any `.html` file in a browser to explore that portal.

Start with **`index.html`** for an overview and navigation between portals.
